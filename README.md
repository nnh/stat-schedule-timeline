# 統計解析スケジュール管理

試験ごとのスケジュールを、Google スプレッドシートのタイムライン表示（ガントチャート）で管理するためのツールです。  
試験一覧に試験名と開始日を入れると、タイムラインにバーが表示されます。終了日を入れなければ、開始日から4か月分のバーになります。

シートの構成・初回設定・開発者向けの情報は [詳細](DETAILS.md) を参照してください。

## 使い方

### 試験を登録する

試験一覧シートに試験名・開始日を入力します。終了日は任意です。

- 試験名は試験情報マスタのプロトコルIDから選べます。マスタにない名前も入力できます（警告表示のみ）。
  - セルに文字を入力すると、入力した文字に一致するプロトコルIDが候補として表示されるので、そこから選べます。
- 終了日を入力すると、タイムラインのバーはその日までになります。空欄なら開始日の4か月後までです。
- 開始日が空欄の場合は、今日の日付に1日だけのバーが表示されます（日付が決まっていないが予定がある試験を忘れないため）。
  - タイムラインでは、カードの詳細の先頭に「（スケジュール未定）」が付きます。
  - 試験一覧では開始日のセルが黄色になります。日付が決まったら入力してください。

### データロックポイントを入れる

データロックポイント列に日付を入力すると、タイムラインにその日だけのカードが表示されます（種別は「★DLP」、色は全試験共通の赤系）。空欄なら表示されません。

### 備考を書く

備考列に入力した内容は、タイムラインのカードの詳細に表示されます。

### 試験を非表示にする

表示状態は空欄のままなら表示されます。非表示にしたいときだけ「非表示」を選ぶと、その試験はタイムラインに表示されなくなります。試験一覧の開始日・終了日はそのまま残ります。

### バーの色を変える

試験名を入力すると、試験名のセルに淡い色が自動で付き、その色がタイムラインのバーの色になります。
同じ試験名が複数行あるときは、すべて一番上の行の色にそろいます（2行目以降の色を手動で変えても、一番上の行の色に戻ります）。
試験名のセルの背景色を手動で変えると、試験一覧のどこかのセルを次に編集したときに、バーの色も変わります（色の変更だけでは反映されません）。

## 制限事項・注意点

- 試験一覧のタイムライン開始・終了の列と、タイムライン用データシートは数式で計算しているため、直接入力しないでください。編集しようとすると警告が表示されるよう、「初期設定」で範囲の保護（警告のみ）をかけています。
- 「初期設定」を再実行すると、試験一覧のヘッダーと自動計算の列の数式を設定し直し、自動計算の列を非表示にします（試験名・表示状態・データロックポイント・開始日・終了日・備考と背景色はそのまま残ります）。
- 試験情報マスタでは、研究管理システムの状態が Completed・Stop・No Support の試験は取り込みません。
